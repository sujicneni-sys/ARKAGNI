How was this result calculated?
y = ln(FRP_Aqua / FRP_SNPP)
ŷ = c + g(t_Aqua) − g(13.6) + regional adjustment
Harmonized FRP = FRP_Aqua × exp(−ŷ)

The model estimates how far the Aqua value is expected to differ from the SNPP reference because of overpass timing relative to 13.6 h, adds a regional offset, then rescales Aqua FRP by the exponential of that estimate. The interval is a split-conformal 80% band calibrated by delay bin. The gate refuses unsupported cells.

Operational safeguards

  • Pixel-level or event-level payloads are rejected; the served unit is a 1° cell-day.
  • The aggregator config hash must match the training aggregation.
  • Scan and delay outside the measured domain are refused.
  • Saturation, plume scattering and canopy occlusion stay not evaluated.
  • The point estimate is not a guarantee; read the interval.

Readable technical methodology

Technical Methodology

The pipeline is reproducible from the frozen inputs, a config hash and a model artifact hash. Every reported number comes from the real tables; unavailable states are labelled rather than filled.

1. Dataset and data provenance

Three FIRMS standard-product cleaned CSVs (MODIS, SNPP, NOAA-20) are frozen read-only. The documented data_hash is SHA-256 of the three per-file SHA-256 digests concatenated in order MODIS, SNPP, NOAA-20. It begins —.

The source archive is preserved untouched. L1 canonicalization types the frozen cleaned baseline and adds explicit validity fields; it never rewrites the input bytes.

2. Data cleaning and validation

Rows are never deleted. A uint8 flag records type != 0, FRP <= 0 and night. The validated set requires all three flags clear. Zero FRP is flagged, not silently repaired; no negative FRP is present in this sample.

validated = (flags & EXCLUDE_MASK) == 0

3. Cell-day aggregation

The unit is one 1° cell-day: (region, sampling window, date, floor(lat), floor(lon)) for one satellite. FRP is summed; pixel count, mean local solar time, mean scan and mean area ratio are retained.

4. Satellite observation pairing

Aqua and SNPP cell-days are inner-joined on the key. Only cells with detections from both sensors are paired, which biases the sample toward larger fires; the dashboard states this everywhere it matters.

5. Delay calculation

lst = (UTC hours + longitude / 15) mod 24
delay_ref = lst_Aqua − 13.6 h
delay_pair = lst_Aqua − lst_SNPP

Times are zero-padded HHMM before parsing: 118 means 01:18 UTC, not 11:08.

6. Model architecture

Seven models are fitted: B0 (no correction), B1 (global scale), B2 (regional scale), P (physics, linear delay / diurnal shape), H (P + ridge-penalised regional offsets), M (gradient boosting) and PR (P + boosted residual). H is served; M and PR stay research-only.

g(t) = ln(b + (1 − b) exp(−(t − t₀)² / (2σ²)))

7. FRP harmonization equation

y = ln(FRP_Aqua / FRP_SNPP)
ŷ = c + g(t_Aqua) − g(13.6) + regional adjustment
FRP_harmonized = FRP_Aqua × exp(−ŷ)

This maps Aqua's cell-day sum to what SNPP would report at 13.6 h, including the sensor-pair scale offset. It is not a pure time shift.

8. Conformal uncertainty estimation

Split-conformal intervals use the absolute out-of-fold residual. The 80% quantile is computed per pre-registered delay bin; bins with fewer than 40 calibration pairs fall back to the pooled quantile. Honest coverage excludes the evaluated sampling block from calibration.

interval = [FRP_h × exp(−q), FRP_h × exp(+q)]

9. Applicability domain

A cell is applicable only when its delay bin has at least 40 calibration pairs and honest coverage of at least 0.70, the delay and scan lie inside the measured 1st–99th percentile domain, and the region is in training. Otherwise the output is null with a reason.

✕ coverage_below_floor✕ insufficient_calibration_pairs✕ delay_outside_calibrated_range✕ region_not_in_training

10. Audit methodology

Folds are whole 5-day sampling windows. Regional transfer is leave-one-region-out. Pairing sensitivity compares cell-day-sum and near-coincident subsets with block-bootstrap intervals. Terra is an out-of-regime test: fit on Aqua, predict Terra. The FRE trend is a naive log-linear fit with a 95% interval and no significance claim when the interval crosses zero.
